The prospective nowcast is an additional, explicitly frozen cohort for the same
GS at MEM game and 36 source-listed candidates. It does not replace the November
18 acceptance cohort or tonight's separately pinned source-only worker.

HTTP bodies in prospective_inputs are original response-body bytes. Each receipt
retains URL, HTTP status, raw body hash, actual retrieval start/completion and
ingestion clocks. Source publication, original historical pregame availability,
legal roster completeness and complete correction ancestry are unknown. Current
retrieval of prior completed games is usable before this new target, not proof
that these bytes existed before those historical games. All current-season
completed games from both schedules are retained: 15 per team, 29 unique games.
The shared game is captured once. Original source files remain unchanged.

The first capture command failed when its second team encountered the already
captured shared game; create-only behavior preserved the first bytes. The resume
command fetched only missing directories. Exact executed scripts are retained as
receipt text. Their initial console streams were not persisted as standalone raw
files; that is an evidence limitation, not a claim those streams were recovered.
Each HTTP operation's original receipt is retained. No source publication or
correction history was synthesized to fill that limitation.

Hosted model/experiment/receipt files are tool-returned UTF-8 text copies with a
terminal newline added by file publication. Only the model copy is expected to
match the original repository artifact byte-for-byte. Receipt text is supporting
metadata, not proof of a new model fit, training replay or historical scoring.
See independent/provenance for the independent read-only hosted provenance check.

For each player the bounded history is CURRENT_TEAM_OBSERVED_WINDOW, not complete
career history. Only explicit positive displayed-minute observations enter the
last-ten played appearances. Return gap counts explicit DNP rows since the last
positive appearance; missing, unknown or played-zero rows in that interval block
that player's feature vector. Team change compares current team to last observed
appearance in this bounded window; no other-team continuity is inferred. Minutes
are ESPN's displayed rounded observation units, not exact seconds. Inference
remains exploratory, conditional on participation, with no team-total normalization.
