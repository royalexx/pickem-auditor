Numerical contract: convert finite non-boolean JSON numbers to Fraction(str(x));
normalize each declared marginal and G/O weights exactly in that domain. Require
identical normalized G/O weights, exact full atom mass equalities, known q/DNP
marginals, complete identity/eligibility/OT/support populations. All positive
G/O columns are the candidate primal measure; zero-weight draws are structurally
checked but do not supply positive support. Minute conservation retains the
explicit inherited 1e-7 minute numerical tolerance; its actual rational maximum
residual is returned. This is not an exact-integer clock or an assertion of
exact real-valued conservation. Tiny positive atoms cannot disappear in LP
feasibility tolerances. New receipt distinguishes this contract from original
floating-point LP fallback.

Proof: the positive conserving columns define a normalized nonnegative primal
measure. Exact sums over every state equal the full declared conditional minute
laws times q. A successful certificate sets each unknown existential q to1;
universal q<=1 is a valid dual upper bound, so attained1 is the full-support
maximum, irrespective of unenumerated columns. Known q is unchanged. All
positive observed columns have positive measure. One measure supports all
witnesses and attains every unknown maximum simultaneously. This sufficient
condition is intentionally stronger than general feasibility; separate extrema
need not share an optimizer. Unknown q remains null in the envelope.

Positive-exposure bound remains qmax*P(minutes>0|played), including played-zero
mass. Required-positive query comparison uses rational bounds before float
serialization. Existing forecast consumer compatibility still retains its
original float numerical tolerance; no exact rational forecast-acceptance claim.

If certificate conditions fail, the opt-in validator invokes the unchanged
complete G0 solver within its original budgets. Unsupported large cases remain
explicitly unresolved; there is no inferred broad operating range or raised
budget. The route receipt names which verifier/numeric contract succeeded.
No scenario discard, O0 substitution, empirical-q authentication, old-law edit,
or unconditional acceptance follows.
