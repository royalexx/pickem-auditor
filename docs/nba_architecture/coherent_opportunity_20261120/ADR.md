# New coherent family; unchanged physical accounting

The user explicitly approved implementing the construction described in the
preceding response: generate compatible statistics together from shared
minutes, opportunities, conversions and events, retain hard accounting, and
require historical validation before release. This is bounded shadow research
under PA-V25-MASTER-2026-11-09/v1.1 and the source-listed subset amendment.

The old saved S1 points/threes marginals cannot all be preserved by an exact
physical coupling. Their immutable forecasts and incompatibility witnesses
remain controls. The new family changes the statistical specification instead
of weakening constraints, clipping outputs, removing outliers or silently
loosening the old fidelity gate.

The new dependency graph is:

```
same admitted source population -> component parameter posteriors
component parameters + one shared G/O -> new chronological joint law
new joint law -> S4 per-player marginals and J joint queries -> C
frozen old S1 -> read-only comparison in C
```

This adds a separately versioned research family and API. It does not rewrite
the canonical legacy S1-to-J graph, introduce a feedback cycle, or make S4 and
J independent votes. The old CLI/contract remains readable; the new CLI is
`scripts/nba_coherent.py`. Existing producers, schemas, default profiles and
production/schedule configuration are unchanged. Canonical full G1/G2 and
scientific investment gates are not granted by this prototype.

Source and target remain fixed before implementation:20 original games,
698 rows,456 ordinary fit rows,35 source-listed target candidates and14
supported players. One closed-writer prospective component fit and one
preregistered64-scenario execution were reviewed. Frozen actual receipts
separate implementation, model admission, execution and later reader review.
No new cohort or source root is smuggled in through a caller label.

Physical event/audit/O code is unchanged. Attempt/conversion draws generate
compatible point/threes intensities; the unchanged path generates every stat
and combo. Numerical cancellation, source/identity/clock failures and declared
resource exhaustion reject the batch rather than repair its draws. Every
request, rejection, unknown and abstention remains accounted for.

The model is modular empirical-Bayes research, with explicit working-likelihood
scope, all14-played conditioning and unknown genuine participation/eligibility.
Zero sensitivity, MC population accuracy, proper target evaluation, historical
validation and release remain open. No historical replacement fitting,
holdout scoring/decompression, ensemble-weight optimization, NUTS restart,
schedule change, merge, deployment or Tier promotion is authorized here.

Rollback is to stop the new explicit CLI, retaining all code/data/decisions
in Git history. Existing runtime, forecasts, priors, controls, sources,
correction ancestry and every old red receipt remain byte-identical to PR192.
