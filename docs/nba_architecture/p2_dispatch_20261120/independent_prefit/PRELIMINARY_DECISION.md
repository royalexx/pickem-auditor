# Independent pre-fit scope assessment

**HOLD_REAL_S_ADMISSION_FOR_EXPOSURE_CONTRACT.** This is a preliminary review of the proposed prospective S1 plan, before receipt of a frozen new SCOPE or implementation. The reviewer authored no implementation repairs and performed no fitting, source recapture, scoring or model admission.

The new user request to investigate and add missing genuine S statistic forecasts supports a bounded inexpensive prospective S1 experiment in principle. It does not authorize backdating the original November 19 freeze, overwriting old forecasts/models, reopening NUTS, fitting weights, scoring holdouts, changing schedules, or promoting predictive or Tier status. A new future target, source cohort, actual data cutoff and later input freeze are appropriate. Fit approval and real artifact admission remain separate checkpoints.

The proposed source plan currently has these issues:

1. The accepted November 19 ADR says: **“Ordinary exposure: source-specific exact duration/exposure required where used; zero/sub30seconds/unsupported accounting excluded with reasons, DNP separate, every row retained.”** Integer displayed ESPN MIN is not exact player exposure. Passing it into native S1's `minutes` denominator as an observed exact value would not satisfy this existing contract. Obtain a genuine seconds or mm:ss exposure witness from a supported source, or secure an explicit approved measurement-contract amendment before fitting/admitting that approximation. A new label saying “approximate” does not itself amend the requirement. This does not invalidate accepted exploratory M0 preparation, whose displayed-history limitations were already disclosed; it prevents that limitation from silently becoming an exact S training exposure claim.

2. “Explicit played positive” is insufficient even when exact seconds are obtained: source rows with `0 < seconds < 30` must be excluded from fitting with a preserved reason, while DNP, played zero, missing and unsupported-accounting states remain distinct. Rounded zero is not proven exact played zero. Rounded MIN=1 does not authenticate a 30-second minimum without supported provider rounding semantics.

3. The accepted real sample `summary-401910016/body.raw` has no `period` under `header.competitions[0].status`. It does have competitor linescores. Its matching captured schedule competition has completed status and `period=4`. A new source-specific join can potentially witness regulation/overtime using exact game/date/team identity, consistent final periods and complete matching linescores. Missing or conflicting witnesses must abstain; never default to four periods or derive duration from player-minute sums.

4. A position field attached to a historical ESPN boxscore is not by itself proof of original game-time role. It is provider metadata observed at capture. If used, freeze the exact semantics as `ESPN_POSITION_BIN_OBSERVED_AT_CAPTURE`, including a deterministic documented PG/SG→G, SF/PF→F, C→C mapping and abstention for ambiguous combinations. Do not claim starter, workload role or authenticated historic on-court role. Native S1 uses all target-player histories across roles and only role-matched other players for the peer prior; that exact trained behavior must be documented.

Before a bounded fit, freeze actual raw game/candidate/training-row populations and exclusion reasons, the source parser/role mapping, fixed native S1 hyperparameters and source hashes. Require `max(source ingested) <= training input cutoff <= fit started <= fit completed <= new input freeze <= forecast < new event start`. Retrieval/ingestion times can witness availability now, without claiming original historical pregame availability.

Replay integer source counts and arithmetic: `PTS=2*FGM+3PM+FTM`, `REB=OREB+DREB`, `3PM<=3PA<=FGA`, `FGM<=FGA`, `FTM<=FTA`, with exact game/player/team identity and dated membership. Preserve all rejected/unknown/DNP/zero/sub30/ambiguous-position observations in denominators. Current metadata cannot overwrite historical team membership. The new source reader and registry need versioned contracts; all 20 accepted old reader/CLI bytes and all historical artifacts must remain unchanged.

A compatible source and reviewed fit receipt can support **genuine source-bound conditional-on-participation, fixed-M0-exposure research forecasts** without establishing predictive accuracy, unconditional outcomes, minute-uncertainty integration, full-team allocation or coherent joint laws. No real model is accepted merely because native `fit` returns an artifact or a registry entry has a hash. After any separately approved fit, an independent exact artifact/source/role/cutoff review and positive/negative replay decision are required before real admission.

The immediate next action is to resolve exact exposure and freeze the new scope and source capability evidence. Source investigation/capture can continue. This preliminary assessment grants **no fit execution or real model admission** for the currently proposed rounded-minute inputs.
