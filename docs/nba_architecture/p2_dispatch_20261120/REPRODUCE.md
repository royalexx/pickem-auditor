## What is implemented

The new numerical dispatcher source-replays P1/P3, fixes exposure to the native
M0 expected_minutes_given_played, and resolves a trained role only through an
immutable reviewed model contract. It verifies target identity/current-team,
exact model/reader/raw-training-source/manifest bytes, training cutoff and dated
historical membership before invoking native predict_conditional. Historical
teams and roles remain dated facts, not overwritten with current assignments.
The native prediction's support and disclosed tail are preserved.

Its law is conditional on participation AND fixed projected M0 minutes. It does
not integrate minute uncertainty or create an unconditional/joint/team law.
Supported minute-exposure families are S1/S2. S3 projected-attempt conversion
cannot receive minutes as attempts; no projected3PA source was supplied.
M1/M2 remain preserved upstream comparators, not selectable exposure variants.

No genuine compatible saved S artifact was found in the bounded repository and
Deepnote file inventories. The real registry is empty. Model admission needs a
separate reviewed code entry binding that exact artifact and source/role/cutoff
contract. Runtime hashes, approval files, reviewer strings and labels cannot
register a model. No fit or held-out evaluation was performed to create one.
