# Workstream 4 — independent matched-cohort comparison / settlement protocol

**Experiment locked for research before Sunday settlement.** Cohort: all original pregame source-supported NFL contracts in a Workstream-1 immutable certified manifest. Preserve unavailable, offered-rejected, DNP/void, push, unsettled, eligible and settled statuses separately; each exact quote is one contract even if both Over and Under are displayed. No synthetic-line cohorts may be compared against real-book economics. Missing component model outputs are `not_available`, never probability 0 or invented by combining other models.

Candidate IDs retained where each original forecast exists: `production_60_40`, `market_only`, `engine_a`, `engine_b`, `bayesian_a`, `bayesian_b`, `strict_nuts`, `ws2_simple`, `ws3_opportunity`, `J1`, `J2`, `J3`. Historical unvalidated versions are NOT authoritative production weights. Determine common support individually for every pair, with the full denominator and all missing/abstained rows. Never compare a union cohort as a matched league table. The frozen official selection rank, if genuinely recorded before kickoff, defines top 5 and top 10; no retrospective selection allowed.

Official outcome (`official_stat`) is not accessed until frozen predictions exist and game is complete. Official stats provider, stat correction version and settlement timing require receipts; `PUSH` arises from equality at exactly the original integer line and is not a void. For non-push settled contracts binary Over Brier `(p_over-I_over)^2` and binary log loss; for all settled including push, **unscaled three-way** Brier `Σ_k(p_k-I_k)^2` and three-way log loss. Count CRPS is exact integer CDF sum when valid PMF exists. Calibration-in-the-large is mean predicted Over minus realized Over rate. Directional hit is based on `p_over` versus `p_under`; ties abstain. For selected picks report claimed side probability versus realized hit, with 3-way push handling separated.

Use **game** as the prespecified primary cluster. Week/date bootstrap is a sensitivity analysis only when adequate independent weeks exist. Paired cluster resamples MUST resample the same contracts for all compared models; 2,000 deterministic game-cluster replicates planned after sufficient outcomes. For one Sunday, report descriptive scores and no promotion claims regardless of nominal edge. Multiple benchmarks/challengers require multiplicity awareness and fresh prospective repeated slates. No synthetic offer score is evidence of actual betting profit. Market-only probabilities require compatible actual two-sided quotes and an explicit no-vig method; without these the column remains missing.

Run `paired_evaluator.py --forecasts <unchanged_merged_frozen_forecasts.json> --settlements <official_receipt_checked_settlements.json> --output <new_versioned_postsettlement_report.json>`. It intentionally cannot collect or rewrite the live source. The merged evaluation input must have complete exact identifiers and `model_id`, and the official settlement input must have unique exact identifiers, `status`, `official_stat` for settled, game date, frozen selection rank if any, original terms and provenance references. This tool is a **research scoring adapter**, not a certified settlement authority.
